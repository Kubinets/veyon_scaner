# 🔍 ARP Scanner для локальной сети

Простой и эффективный скрипт для сканирования сети **192.168.1.0/24** и проверки наличия заданных MAC-адресов в ARP-таблице.

## 📋 Описание

Скрипт автоматически:
- 🔎 Сканирует все IP-адреса в диапазоне `192.168.1.1 - 192.168.1.254`
- ⏳ Ожидает завершения ICMP-запросов (ping)
- 📊 Собирает ARP-таблицу текущей сети
- 🎯 Сравнивает найденные устройства с предустановленным списком MAC-адресов
- 📋 Выводит результат в удобной табличной форме

## 🎯 Назначение

Идеально подходит для:
- Мониторинга наличия конкретных устройств в сети
- Быстрой проверки подключения оборудования по MAC-адресам
- Администрирования локальной сети
- Отладки сетевых подключений

## 🚀 Использование

1. Сохраните скрипт
2. Запустите от имени администратора (рекомендуется)
3. Дождитесь завершения сканирования
4. Просмотрите результаты в консоли

## 📊 Пример вывода
```
============================================================
IP-адрес         MAC-адрес
============================================================
192.168.1.10     f4-b5-20-5a-47-dc
192.168.1.25     f4-b5-20-5a-44-f7
[Не найден]      f4-b5-20-5a-3a-24
============================================================
```
## 🔧 Настройка

Для сканирования своих устройств отредактируйте следующие строки в скрипте:

```batch
set "mac1=f4-b5-20-5a-47-dc"
set "mac2=f4-b5-20-5a-44-f7"
rem ... добавьте свои MAC-адреса
```

## 📝 Примечания

- Скрипт использует кодировку UTF-8 (`chcp 65001`)
- Временный файл `arp_table.txt` автоматически удаляется после работы
- Требуются права администратора для корректного получения ARP-таблицы
- Время ожидания ping ответов можно изменить, отредактировав параметр `-n 2`


## ⚠️ Требования

- Windows OS
- Подключение к сети `192.168.1.0/24`
- Права администратора (рекомендуется)
